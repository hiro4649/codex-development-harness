# Skill: IRIS Boundary Reviewer

## title
IRIS Boundary Reviewer

## purpose
Preserve IRIS Phase ownership, I/O contracts, Core / Adapter boundaries, and candidate / approved / commit / execution separation.

## whenToUse
Use for IRIS Phase, adapter, persistence, review path, or execution boundary changes.

## procedure

- IRIS_SPEC_AUTHORITY.md was consulted first.
- Phase00 canonical enums and Source of Truth priority are not violated.
- The owning Phase responsibility and Phase I/O contract are not expanded or bypassed.
- Core / Adapter boundary is preserved.
- candidate / approved / commit / execution separation is preserved.

## pitfalls

- world_command is not generated by Core.
- External observation remains reference only.
- Public output, reports, diagnostics, and review notes use safe summaries only.
- Code and tests do not rewrite specification meaning.

## verification
Require safe summary evidence that the relevant authority section, owning Phase, I/O boundary, and adapter handoff remain unchanged unless explicitly approved.

## safeOutput
Return only safe summaries, file names, check names, PASS/FAIL, and residual risks. Do not output secrets, endpoint values, raw payloads, raw logs, or private paths.
